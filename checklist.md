## Portability Checklist

- [ ] [Dependencies are defined in containers.](https://github.com/caffiendFrog/repo-to-go/blob/main/guide/dependencies.md)
- [ ] [Default compute resources can be customized by the user.](https://github.com/caffiendFrog/repo-to-go/blob/main/guide/compute-resources.md)
- [ ] [Required files are provided, or there is automation to re-build them.](https://github.com/caffiendFrog/repo-to-go/blob/main/guide/external-resources.md)
- [ ] [No hard-coded absolute paths. Paths are relative to the repo or working directory.](https://github.com/caffiendFrog/repo-to-go/blob/main/guide/paths.md)
- [ ] [Provide a small test configuration + dataset for new users to run the software.](https://github.com/caffiendFrog/repo-to-go/blob/main/guide/test-config.md)
