## Portability Checklist

- [ ] Dependencies are defined in containers.
- [ ] Default compute resources can be customized by the user.
- [ ] Required files are provided, or there is automation to re-build them.
  - E.g. support standard pre-built reference genomes, and also allow users to bring their own custom genomes.
- [ ] No hard-coded absolute paths. Paths are relative to the repo or working directory.
- [ ] Provide a small test configuration + dataset for new users to run the software.
